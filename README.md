# 🕹️ Unity 2D Topdown Interaction Game

## 📌 개요 (Overview)

유니티 2D 기반의 오픈 탑다운 게임으로,  
**구조물 및 NPC와의 상호작용 시스템**을 중심으로 자유롭게 탐험하고 체험하는 형태의 게임을 구현하는 것이 목적입니다.

---

## 🚀 주요 기능 (Features)

1. **플레이어 주변 상호작용 감지 시스템**  
   - `Raycast`를 활용해 주변에 특정 인터페이스를 가진 컴포넌트를 탐지  
   - 인터페이스 기반으로 구조물 및 NPC의 상호작용 분리

2. **미니게임 결과 저장 및 리더보드 시스템**  
   - 미니게임 종료 시 결과 데이터를 JSON 파일로 저장  
   - 메인 씬에서 리더보드 UI를 통해 불러오기 및 정렬 표시

3. **상호작용 가능한 오브젝트 외곽선 표시**  
   - Shader Graph를 활용한 2D 외곽선 효과 적용  
   - 상호작용 가능 오브젝트 탐지 시 하이라이트 처리

---

## 🧩 트러블슈팅 (Troubleshooting)

### 1. 외곽선 셰이더 문제
- **문제**: 외곽선의 두께 값을 조절해도 실제 두께가 변경되지 않음  
- **원인**: 알파 채널 기준 offset 계산 오류로 추정  
- **해결**: 아직 해결하지 못했고, 추후 추가 조사 및 수정 예정

### 2. 미니게임 (The Stack) 리팩토링
- **문제**: 기능이 한 파일에 밀집되어 있어 유지보수가 어려움  
- **해결**: 기능 단위로 코드를 분리한 뒤, 사용되지 않는 변수 제거 및 참조 정리

### 3. 상호작용 인터페이스 구성
- **문제**: 상점 + 퀘스트 기능을 동시에 제공하는 NPC 설계 문제  
- **해결**: `IInteractable`을 NPC에 다중 컴포넌트로 등록, 다형성으로 처리

### 4. 리더보드 데이터 관리
- **문제**: 게임 결과 데이터를 리더보드가 있는 메인 씬에서 접근해야 했음  
- **해결**: `DontDestroyOnLoad` 대신 JSON 파일 저장으로 구조 변경,  
  메인 씬 최초 로드 시 및 일정 주기마다 로드하도록 구현

## 🔮 향후 계획 (Roadmap)

1. 탑승 가능한 탈것 시스템 구현
2. 구조물별 상호작용 로직 세분화 (상점, 퀘스트 등)
3. 커스텀 캐릭터 생성 및 외형 변경 시스템
4. 상점 기능 구현 및 UI 연동
5. 외곽선 효과 및 셰이더 그래프 성능 개선
